## BullMQ is a high-level job queue framework that uses Redis internally, just like an ORM uses MySQL under the hood to simplify complex operations.

## BullMQ cannot work without Redis
## BullMQ stores jobs, states, retries, and delays inside Redis.
  👉 Redis is the core engine BullMQ depends on.

## Redis can work without BullMQ
## Redis is a general-purpose data store (cache, pub/sub, streams, locks).
  👉 BullMQ is just one possible use case built on top of Redis.
